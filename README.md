### 🔧 O que eu faço

- 📡 **Firmware para gateways IoT** com ESP32 / ESP32-S3: LTE com chip M2M, GNSS, ESP-NOW e OTA
- 🔐 **Controle de acesso** por RFID (PN532 via SPI) e provisionamento de dispositivos
- 🔁 **Comunicação em tempo real** com MQTT entre dispositivos, servidores e apps
- 📱 **Apps e sistemas de gestão** que conversam com o hardware em campo
- 🏷️ Ferramentas práticas, como gerador de etiquetas EAN-13 para impressora térmica
